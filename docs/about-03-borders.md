# JankyBorders

Lightweight window border utility for macOS. [GitHub](https://github.com/FelixKratz/JankyBorders)

## Why

With a tiling window manager, it's not always obvious which window is focused. JankyBorders adds a visible border around the active window so you can instantly tell where your focus is.

## Config

Lives in `~/.config/borders/bordersrc`. Started automatically by AeroSpace via `after-startup-command` in the AeroSpace config.
